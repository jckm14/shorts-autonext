# Shorts Auto-Next

Plays YouTube Shorts back to back, advancing automatically when each one ends.

- `docs/` — Home Screen web app (served by GitHub Pages). Plays Shorts from channels, playlists, or individual links you add.
- `ShortsAutoNext/` + `ShortsAutoNext.xcodeproj` — native iOS app that wraps the real YouTube Shorts feed. The "Build IPA" workflow produces an unsigned `.ipa` for sideloading.

## Install the web app on iPhone
Open the GitHub Pages URL in Safari, tap Share, then **Add to Home Screen**.
